# 吃啥转盘 · 使用说明

> 一个转盘，转到哪道就吃哪道。不用再站在食堂门口纠结十分钟。

---

## 一、怎么打开

### 方式 1：直接双击（最简单）

打开 `dist/吃啥转盘.html`，用浏览器打开就行。
不需要装东西、不需要联网（拍照识别那一步除外）。

### 方式 2：装到手机上（推荐，像 App 一样用）

1. 把 `dist/吃啥转盘.html` 发到手机：微信 / QQ / 数据线 / 网盘都行。
2. 用手机浏览器打开它（Chrome / Edge / 三星浏览器 / Safari 都可以）。
   - 微信里直接点可能被限制，选「用其他浏览器打开」。
   - 有的安卓文件管理器要先选「用浏览器打开」。
3. 加到主屏幕，以后一键全屏打开：
   - iPhone Safari：底部分享按钮 → 添加到主屏幕
   - 安卓 Chrome：右上角 ⋮ → 添加到主屏幕

### 方式 3：安卓 APK

去 GitHub 仓库的 **Releases** 页面下载 `what-to-eat-wheel-v1.0.0-debug.apk`，传到手机上点安装
（首次安装需要允许「安装未知来源应用」）。桌面出现「吃啥转盘」图标，点开即用。

包名 `com.mengxiangbaofu.whattoeatwheel`，支持 Android 7.0 以上，自签名。
如果之前装过同包名的其它版本，需要先卸载旧的。

## 二、加菜

在「🍽 菜品」里那个输入框打字，回车就加上了。

- **一次加多道**：粘贴多行文字（一行一个），或者用顿号/逗号分隔，例如
  `可乐鸡翅、糖醋排骨、鱼香肉丝`
- **重复的会自动跳过**，不会加两遍。
- 加错了就点那行右边的 **⋯** →「删掉这道菜」。

## 三、大类和小项（重点）

像你们食堂这种：

```
滑蛋饭（大类）
 ├─ 麻辣鸡丁滑蛋饭
 ├─ 五花肉滑蛋饭
 └─ 番茄滑蛋饭
```

本应用会自动把名字里带相同后缀的菜归成一个大类，**不需要你手动建**。

### 勾选规则

| 你点的东西 | 效果 |
|---|---|
| 大类前面的方框 | 这个大下的**所有**菜都放上转盘 |
| 某一道菜前面的方框 | 只有这一道放上转盘 |
| 大类名字 | 折叠 / 展开这个大类 |
| **⋯** 按钮 | 打开这一项的菜单（改名、换类、删除、整体上盘…） |

### 整个大类当一个选项（菜多的时候很实用）

菜单一多，每个菜都铺一个扇区转盘就挤了。而且真去食堂，本来就是**先定吃哪一类，
到了窗口再挑具体哪道**。

点大类头上那个「**＋ 整体**」按钮就行——这一个类立刻进转盘，占一个位置。

| 按钮状态 | 点一下会怎样 |
|---|---|
| 灰色 `＋ 整体` | 整个大类进转盘，占**一个**位置，写大类名 |
| 绿色 `✓ 整体` | 从转盘撤下 |

切成整体之后：

- 它下面的菜会**置灰、勾不了**（因为已经不由它们决定转盘了）；
- 大类前面那个方框，管的是「这一类整个上不上盘」；
- 转到它的时候，结果会写「这一类里有 N 道，到了窗口再挑一道」。

想改回「每道菜各自占一个位置」：再点一下那个绿色按钮，
或者在 **⋯** 菜单里选「改成按菜品上转盘」。

大类和小项可以混着来：比如「滑蛋饭」整个占一个位置，再加一道「兰州牛肉面」
单独占一个位置，转盘上就是 2 个扇区。

### 「✨ 智能归类」按钮

如果有些菜没归好，点一下它，会按菜名后缀重新分大类。
比如你加过「红烧牛肉面」和「兰州牛肉面」，它会自动建一个「牛肉面」大类。

### 手动调整

- 点某道菜右边的 **⋯** → 「只转这一道」「临时撤下 / 放回」「改名 / 换大类」「删掉」。
- 点大类右边的 **⋯** → 「重命名这个大类」「往这个大类里加菜」「只转这个大类」「删除大类」。
- **自己建一个大类**：点上面的「＋ 新建大类」，起个名字就行，建完会顺带问你要不要马上往里加菜。
- 给某道菜换大类时，「归属大类」里选「＋ 新建一个大类…」也能现场建一个新的。
- 改大类名时，如果改成另一个已有大类的名字，两个大类会**合并**。

## 四、拍照识别（可选）

拍一张食堂菜牌，自动认出上面有什么菜，确认后加进转盘。

**需要先配一个视觉模型的 API Key**，去「⚙️ 设置」里填。这一步是可选功能，
不配也能用手动加菜 + 转盘。

### 推荐配置（学生党零成本）

| 服务商 | 模型 | 说明 |
|---|---|---|
| **智谱 AI**（推荐） | `glm-4.6v-flash` | 目前完全免费，识别菜牌够用 |
| 硅基流动 | 点「拉取」选 | 有免费模型 |
| 阿里云百炼 | `qwen3-vl-plus` | 新用户每个模型送 100 万 token（90 天） |

应用里内置了 **17 家**服务商（智谱 / 硅基流动 / 百炼 / 火山方舟 / 腾讯混元 / 百度千帆 /
讯飞星火 / MiniMax / 阶跃星辰 / 魔搭 / Kimi / Gemini / OpenAI / 本地 Ollama…），选一家就行。

操作：

1. 去对应官网注册，拿到 API Key（一般形如 `xxxxx.yyyyy`）。
2. 回到应用 →「⚙️ 设置」→ 选服务商。
3. 把 Key 填进「API Key」：**点旁边的 📋 直接从剪贴板粘贴**，或者长按输入框粘贴。
   不用手敲（Key 很长，敲错一个字符就白费）。
4. **点「拉取」选模型**——它会列出这个 Key 能用的模型，名字里带视觉标志的排最前面，
   点一个就填进去了，不用自己去控制台翻。
5. 点「**测试连接**」。这一步会**带一张小图**去测，
   所以看到「连接正常，而且这个模型能收图片」才是真的配好了。
6. 「📷 拍照识别」→ 拍照或从相册选图 → 等 5~20 秒 → 改改不认识的菜名 →「全部加入转盘」。

> ⚠️ **模型必须能看图**。名字里通常带 `v` / `vl` / `vision`（比如 `glm-4.6v-flash`、
> `qwen3-vl-plus`）。填了纯文字模型的话，会提示「这个模型不收图片」——
> 那不是网络问题，换个带 V 的模型名就行。
>
> 「拉取」列表里标「**未标注**」的不代表不能看图，只是名字里没写
> （比如 `Qwen/Qwen3.5-4B`）。拿不准就用「测试连接」验一下。

> ⚠️ **模型必须能看图**。名字里通常带 `v` / `vl` / `vision`（比如 `glm-4.6v-flash`、
> `qwen3-vl-plus`）。填了纯文字模型的话，会提示「这个模型不收图片」——
> 那不是网络问题，换个带 V 的模型名就行。
>
> 如果提示「模型输出被截断了，只认出前 N 道」，说明这张菜牌上的菜太多、
> 一次认不完。可以再拍一次，或者分两张拍。

### 识别不出来 / 报跨域错误？

浏览器出于安全限制，不让网页直接调第三方接口（叫「跨域」CORS）。两种情况分开处理：

- **电脑上开本地服务器用（`npm run serve`）**：在设置里勾上「通过本地代理请求」，
  请求会经本地服务器转发，彻底没有跨域问题。
- **手机 App 版**：**不用勾**（也勾不上，设置里那一项是灰的）——App 走的是原生网络请求，
  本来就不受跨域限制。
  如果你在 App 里看到报错里带着 `<!doctype html>` 这种网页源码，
  那是这个开关被错误地打开了（旧版本才有），升级到 v1.0.5 以后就不会了。

**其他常见错误**：

| 报错 | 多半是 |
|---|---|
| `API Key 不对或没有权限（HTTP 401/403）` | Key 复制错、或者没开通对应模型 |
| `接口地址或模型名不对（HTTP 404）` | base URL 或模型名填错 |
| `请求超时` | 网络慢，或者图片太大 |
| `接口返回的不是 JSON` 且内容是网页源码 | 接口地址填成了普通网址 |

## 五、数据存在哪

全部存在**你这台设备本地**（浏览器的 localStorage），不会上传到任何地方。
API Key 也一样，只存在本机。

换手机 / 换浏览器要搬数据：**设置 → 导出备份**，得到一个 `.json` 文件；
在新设备上 **设置 → 导入备份** 就能恢复（备份文件里**不含 API Key**，需要重新填）。

> ⚠️ 清理浏览器数据 / 无痕模式会连菜谱一起清掉，重要的就先导出备份。

## 六、小技巧

- 电脑上按 **空格键** 就能转。
- 抽中之后有三个选择：「**✅ 就吃这个**」把结果定下来（当天打开都显示「今天就吃它」）、
  「再转一次」、「从转盘移除」（今天不想吃它了）。
- 定下来之后想反悔，点「换一个」就行。
- 设置里可以开「抽中后从转盘移除」，转到过的不再重复出现。
- 「最近」那一行是你最近抽到过的菜，方便回头看。

## 七、常见问题

**Q：转盘上什么都没有？**
A：说明一道菜都没勾上。点「全选」，或者去「菜品」里勾几道。

**Q：菜名太长，转盘上显示不全？**
A：转盘上会用「…」截断，但抽中之后结果卡片里显示的是完整名字。

**Q：扇区太多，字都看不清了？**
A：超过三十几道菜时扇区会变得很窄，建议用「大类」控制一下，
    一次只把想吃的那些勾上再转——这也是这个应用设计分类的意义。

**Q：会不会转到我已经吃腻的？**
A：设置里打开「抽中后从转盘移除」，转过一次就自动下盘。
