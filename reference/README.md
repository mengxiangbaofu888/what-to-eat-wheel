# reference/ · 参考资料

这个文件夹里放的**不是本项目（吃啥转盘）的代码**，是最初做需求调研时收集的参考资料，
原来散在工作区根目录，后来收拢到这里。

## 这里有什么

| 文件 | 是什么 |
|---|---|
| `吃啥好呢.html` | 「吃啥好呢」的单文件离线版（479 KB），内置 355 道真实菜谱 |
| `吃啥好呢.apk` | 上面那个的安卓包（190 KB，包名 `com.jonssonyan.whattoeat`） |
| `吃啥好呢-使用说明.txt` | 它的说明文件（原文件名就叫 `使用说明.txt`，太笼统，加了个前缀） |

## 它和本项目什么关系

这三份东西来自 [jonssonyan/what-to-eat](https://github.com/jonssonyan/what-to-eat)
（Next.js + Prisma + MySQL 的全栈菜谱推荐项目）—— 也就是最开始提出的参考项目。

本项目（吃啥转盘）和它的定位**完全不同**：

| | 吃啥好呢 | 吃啥转盘 |
|---|---|---|
| 干什么 | 内置 355 道菜谱，按口味/难度/时间筛选后随机推荐 | 你自己往里加菜，按大类/小项挑范围，转盘决定 |
| 数据 | 作者维护的菜谱库 | 全部是用户自己加的 |
| 形态 | 单文件 HTML + APK | 单文件 HTML + Capacitor APK + 拍照识别 |

之所以留着它们，是因为「拍一张食堂菜牌自动认菜」这个想法当初就是从这里延伸出来的，
偶尔翻一翻可以做对照。
